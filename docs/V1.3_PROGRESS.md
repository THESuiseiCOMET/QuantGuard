### 本机验证环境问题与复现

- 首次 Java 执行：176 条中 173 通过，3 条 H2 启动报错，没有 skip。根因位于 JDK HttpClient/Selector 创建本地 Unix-domain socket 时 `Invalid argument: connect`，并非外部行情请求失败。
- 单独用不依赖项目的 Selector.open()/HttpClient.newHttpClient() 探针复现同样问题；默认临时路径为 `C:\Users\BRANCE~1\AppData\Local\Temp\`。强制 IPv4 无效。
- 指定独立的 `jdk.net.unixdomain.tmpdir` 后探针和全部 Java/H2 测试通过。此参数只用于本次测试 JVM，没有修改生产配置、依赖或断言，也没有关闭安全软件。
- 前端 npm ci 首次 ECONNRESET，降低并发后按原 package-lock.json 重试成功；锁文件未变。
- Python 测试有一条 Starlette/AnyIO 弃用警告；Java 保留 H2/Flyway 兼容提示；前端保留大 chunk 警告，均未隐藏。
