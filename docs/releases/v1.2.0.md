# QuantGuard v1.2.0

## 中文

QuantGuard v1.2.0 将本地模拟交易系统封装为 Windows 11 x64 桌面客户端。应用内置 Vue 前端、Python 行情服务、Java 后端、Java 21 Runtime 和 H2 File 数据库，不要求用户安装开发环境或 MySQL。

### 主要变化

- 新增 Tauri 2 Windows 桌面外壳和当前用户 NSIS 安装包。
- Python 行情服务使用 PyInstaller `onedir` 自包含运行时。
- Java 后端使用 `jpackage --type app-image` 携带精简 Java 21 Runtime。
- 桌面模式使用 `%APPDATA%\QuantGuard\` 下的 H2 File 数据库。
- 自动选择未占用的本机回环端口，不依赖固定的 8001、8080 或 5173。
- 依次启动 Python 和 Java，等待健康检查后再显示业务界面。
- 正常退出和强制结束时使用 Windows Job Object 管理应用创建的进程树。
- 支持单实例启动、失败阶段提示和重试。
- 默认使用 BaoStock 与 AKShare 的无 Token 历史行情；Tushare 保留为开发或服务器模式下的可选 Provider。
- 支持 A 股股票、ETF 和指数的代码或名称搜索及历史未复权日 K。指数仅用于行情查看，不允许下单。

### 安装

1. 下载 `QuantGuard_1.2.0_x64-setup.exe` 及同名 `.sha256` 文件。
2. 使用 SHA-256 工具核对安装包摘要。
3. 双击安装包，按当前用户完成安装。
4. 首次启动时等待本地 Python 和 Java 服务就绪。

当前社区版本未进行商业代码签名，Windows 可能显示 SmartScreen 提示。请只从项目的正式 GitHub Release 下载，并核对 SHA-256；不要关闭或绕过安全软件。

### 系统和网络要求

- Windows 11 x64。
- WebView2 Runtime。安装包使用在线 bootstrapper；系统缺少 WebView2 时需要网络完成依赖安装，当前版本不承诺完全离线安装。
- 首次证券目录搜索和行情同步需要访问外部数据源。
- 已保存在本地的账户、组合、订单、成交、持仓、资金流水和 K 线可在上游不可用时继续查看。

### 数据、日志和卸载

- 数据：`%APPDATA%\QuantGuard\data\`
- 日志：`%APPDATA%\QuantGuard\logs\`
- 配置和运行状态：`%APPDATA%\QuantGuard\config\`、`%APPDATA%\QuantGuard\runtime\`

卸载应用默认保留整个 `%APPDATA%\QuantGuard\` 目录，因此重新安装后可以继续使用原有本地数据。需要彻底清除时，请先备份，再在 QuantGuard 和其后台进程完全退出后手动删除该目录。

### 备份与恢复

1. 完全退出 QuantGuard。
2. 在任务管理器中确认 QuantGuard、其 Java 后端和 Python 行情服务均已结束。
3. 复制整个 `%APPDATA%\QuantGuard\data\` 目录作为备份。
4. 恢复前再次确认所有进程已结束。
5. 用备份替换数据目录后重新启动客户端。

不要在应用运行时复制 H2 数据库文件。日志通常不需要备份；排查问题时可以连同 `logs` 目录单独保存。

### 安全与完整性

每个候选安装包由 Windows Desktop CI 从干净仓库构建，并随附 SHA-256 文件和构建摘要。Tauri capability 保持最小权限，窗口只允许访问应用资源和本机回环服务。安装包不应包含 Token、密码、用户数据库、测试日志或开发环境。

### 已知限制

- 不支持实时行情、分钟行情或复权行情。
- ETF 数据上游可能偶发不可用；此时会显示明确错误，本地已有数据不会被删除。
- 证券目录为进程内缓存，Python 服务重启后的首次搜索需要网络。
- 当前版本未进行商业代码签名，也没有自动更新。
- WebView2 缺失时的依赖安装需要网络。
- H2 2.4 可能显示 Flyway 尚未充分验证该版本的提示；迁移与持久化测试仍作为发布门禁。
- QuantGuard 仅用于本地模拟分析，不连接真实券商，也不执行真实交易。

## English

QuantGuard v1.2.0 packages the local trading simulator as a Windows 11 x64 desktop application. It bundles the Vue frontend, Python market-data service, Java backend, Java 21 Runtime, and H2 File database, so users do not need a development toolchain or MySQL.

### Highlights

- Tauri 2 desktop shell and a per-user NSIS installer.
- Self-contained PyInstaller `onedir` market-data runtime.
- Spring Boot backend packaged with `jpackage --type app-image` and a bundled Java 21 Runtime.
- H2 File persistence under `%APPDATA%\QuantGuard\`.
- Dynamic loopback ports instead of fixed dependencies on 8001, 8080, or 5173.
- Ordered Python and Java startup with health-gated UI readiness.
- Windows Job Object containment for normal and forced process-tree cleanup.
- Single-instance behavior, visible startup stages, and retry support.
- Token-free BaoStock and AKShare historical data by default. Tushare remains an optional Provider for development or server mode.
- Code/name search and unadjusted daily bars for A-share stocks, ETFs, and indexes. Indexes are view-only and cannot be traded.

### Installation

1. Download `QuantGuard_1.2.0_x64-setup.exe` and its `.sha256` file.
2. Verify the SHA-256 digest.
3. Run the per-user installer.
4. Allow the local Python and Java services to become ready on first launch.

This community build is not commercially code-signed, so Windows may display a SmartScreen warning. Download only from the official GitHub Release and verify SHA-256. Do not disable or bypass security software.

### System And Network Requirements

- Windows 11 x64.
- WebView2 Runtime. The installer uses an online bootstrapper; a machine without WebView2 needs network access, so this release does not guarantee a fully offline installation.
- Initial catalog search and market-data synchronization require upstream network access.
- Existing local accounts, portfolios, orders, trades, positions, cash ledger records, and candlesticks remain viewable when upstream services are unavailable.

### Data, Logs, And Uninstall

- Data: `%APPDATA%\QuantGuard\data\`
- Logs: `%APPDATA%\QuantGuard\logs\`
- Configuration and runtime state: `%APPDATA%\QuantGuard\config\` and `%APPDATA%\QuantGuard\runtime\`

Uninstalling the application keeps `%APPDATA%\QuantGuard\` by default, allowing a later installation to reuse local data. To remove everything, back up first, fully stop QuantGuard and its services, and then delete that directory manually.

### Backup And Restore

1. Fully exit QuantGuard.
2. Confirm in Task Manager that QuantGuard, its Java backend, and its Python market-data service have stopped.
3. Copy the entire `%APPDATA%\QuantGuard\data\` directory.
4. Stop all processes again before restoring.
5. Replace the data directory with the backup and restart the client.

Do not copy live H2 database files while the application is running. Logs are optional for backup but useful for diagnostics.

### Security And Integrity

Each candidate installer is built by Windows Desktop CI from a clean checkout and accompanied by a SHA-256 file and build summary. Tauri capabilities remain minimal, and the window can reach only packaged resources and loopback services. The installer must not contain tokens, passwords, user databases, test logs, or development environments.

### Known Limitations

- No real-time, minute, or adjusted market data.
- ETF upstream availability can be intermittent. The client reports a clear error and preserves existing local data.
- The instrument catalog is cached in process; its first search after a Python restart requires network access.
- The current release is unsigned and has no automatic updater.
- Installing WebView2 on a machine where it is absent requires network access.
- H2 2.4 may trigger Flyway's not-yet-fully-verified warning; migration and persistence tests remain release gates.
- QuantGuard is for local simulation only. It does not connect to a real broker or execute live trades.
